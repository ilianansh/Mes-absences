# INSTALLATION

Mes absences peut être installée sur votre écran d'accueil :

Android : Ouvrez le lien dans Google Chrome, appuyez sur le menu, puis sélectionnez « Installer raccourci de l'application » et installer l'application.
iOS : Ouvrez le lien dans Safari, appuyez sur le bouton de partage, puis sélectionnez « Sur l'écran d'accueil ».

...Une fois installée, l'application est accessible directement depuis votre téléphone.

# Confidentialité et stockage des données

Mes absences fonctionne sans compte utilisateur et sans serveur de stockage distant.
Toutes les données sont enregistrées localement dans le navigateur de l'utilisateur. Elles ne sont ni transmises à un serveur externe ni accessibles par les autres utilisateurs de l'application.
Attention : Les données locales peuvent être perdues si vous effacez les données de votre navigateur ou désinstallez l'application. Pensez à effectuer régulièrement une sauvegarde grâce à la fonctionnalité d'export.
